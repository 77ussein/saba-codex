# ICONOGRAPHY


1. Use clean, simple line icons with consistent stroke thickness.

2. Avoid overly detailed or colorful icons.

3. Keep icons consistent in style and proportion across all touchpoints.

4. Size icons for clarity and legibility.

5. Align icon style with the brand’s modern luxury tone.


## ICONS LIBRARY


Specify a consistent icon set such as Feather Icons or Google’s Material Symbols to ensure visual consistency across all digital and print applications.
