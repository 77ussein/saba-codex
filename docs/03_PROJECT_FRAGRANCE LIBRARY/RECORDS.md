# FRAGRANCE RECORDS

The SAB’A Fragrance Records system defines how official fragrance information, development versions, and approved compositions are documented and maintained.

Its purpose is to provide a reliable, traceable record for every SAB’A fragrance.

---

## 1. Record Purpose

Each fragrance record should provide a clear reference for:

- Fragrance identity
- Creative direction
- Development status
- Formula versions
- Evaluation results
- Approval status
- Relevant technical information

---

## 2. Fragrance Record

Each approved fragrance should have a dedicated record containing the information required to identify and manage it.

The record may include:

- Fragrance Name
- Fragrance Code
- Concept
- Olfactive Classification
- Fragrance Profile
- Current Formula Version
- Development Status
- Approval Status

Only relevant information should be included.

---

## 3. Formula Versions

Each significant formula version should be uniquely identified.

Version records should maintain:

- Version Number
- Date
- Changes
- Evaluation Status
- Development Notes

Only the approved version should be treated as the official composition.

---

## 4. Status Control

Fragrance records should clearly distinguish between:

- Concept
- Development
- Testing
- Approved
- Discontinued
- Archived

Unapproved versions must not be treated as final.

---

## 5. Traceability

Fragrance records should allow the development history of a fragrance to be traced from its initial concept to its approved version.

Changes should remain identifiable and documented.

---

## 6. Confidentiality

Formula details and sensitive development information should be controlled and accessed only when required.

Public-facing fragrance information should remain separate from confidential formulation records.

---

## 7. Core Principle

The SAB’A Fragrance Records principle can be summarized as:

> **Every fragrance decision should be identifiable, traceable, and properly recorded.**

The records system protects the continuity, consistency, and long-term knowledge of the SAB’A fragrance house.
