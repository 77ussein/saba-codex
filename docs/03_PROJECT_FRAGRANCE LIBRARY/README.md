FRAGRANCE LIBRARY

The SAB’A Fragrance Library is the central reference system for the development, documentation, evaluation, and management of SAB’A fragrances.

It focuses specifically on the fragrance itself, including its creative direction, structure, materials, development, evaluation, and official records.

The library supports the SAB’A Product system while keeping fragrance-specific knowledge and decisions organized in one controlled reference.

⸻

Purpose

The Fragrance Library exists to:

* Document SAB’A fragrance knowledge and standards.
* Support the development of new fragrances.
* Maintain consistent fragrance evaluation.
* Record approved fragrance information and formula versions.
* Preserve development history and discontinued work.
* Provide a reliable reference for future fragrance development.

⸻

Scope

The library covers:

* Fragrance Philosophy
* Fragrance Architecture
* Fragrance Families
* Fragrance Materials
* Fragrance Development
* Fragrance Evaluation
* Fragrance Records
* Fragrance Archive

Product-level requirements such as bottle specifications, packaging, and physical product standards remain within 02_PRODUCT and related Codex sections.

⸻

Core Principle

The SAB’A Fragrance Library should remain:

Accurate → Controlled → Concise → Consistent → Traceable

Only approved information should be treated as official.

Unapproved concepts, experiments, and temporary formulations should remain clearly identified as development material.
