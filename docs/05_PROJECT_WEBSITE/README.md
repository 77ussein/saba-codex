# 05_WEBSITE

## Purpose

This folder defines the complete digital experience of SAB’A.

The website is not treated as a conventional online store.

It is the digital house of SAB’A — the primary environment through which visitors discover the identity, heritage, creations, experience, and relationship of the house.

The objective is to create a website that feels:

**Distinct. Refined. Emotional. Immersive. Effortless.**

The website must build desire before transaction and maintain the same standard after purchase.

---

# Website Experience Principle

The website follows one continuous relationship:

**Identity → Curiosity → Emotion → Trust → Desire → Experience → Purchase → Memory → Continuity**

Every document in this folder contributes to that sequence.

No individual feature should be designed in isolation.

# Cross-Channel Principle

A customer may discover SAB’A through social media, arrive at the website, purchase a creation, receive an email, communicate through WhatsApp, and later return through their customer account.

The experience must remain coherent throughout.

For example:

**Instagram → Website → Product → Purchase → Email → WhatsApp → Account → Loyalty**

The customer should feel that every step belongs to SAB’A.

---

# Commercial Philosophy

The website exists to sell.

But selling is not the first impression.

The commercial relationship should emerge naturally from:

**Identity → Understanding → Trust → Desire → Purchase**

Promotions, coupons, competitions, and rewards may exist, but they must not turn the website into a discount-driven environment.

SAB’A should create value through:

- Product
- Story
- Experience
- Recognition
- Access
- Service
- Relationship

---

# Heritage Principle

The website must protect the cultural foundation of SAB’A.

Heritage should inform:

- Structure
- Storytelling
- Atmosphere
- Language
- Experience

It should not be reduced to superficial decoration.

The digital expression may be contemporary.

The foundations remain authentic.

---

# Technology Principle

Technology serves the experience.

The website should use technology where it creates meaningful value through:

- Performance
- Personalisation
- Discovery
- Assistance
- Interaction
- Service

Technology should never become the identity of the website.

The visitor should remember SAB’A, not the technology used to build it.

---

# Evolution

The website is expected to evolve.

New:

- Products
- Collections
- Campaigns
- Features
- Services
- Channels
- Technologies

may be introduced over time.

However, evolution must never mean abandoning the foundations.

The website should grow while remaining recognisably SAB’A.

**Mobile Experience** defines adaptation to mobile.

**Website Standards** define the final quality threshold.

Together they form the complete website framework.

---

# Working Rule

When a new website idea, feature, campaign, or requirement appears, do not immediately create a new document.

First ask:

**Where does this belong within the existing architecture?**

If it belongs naturally inside an existing document, integrate it there.

New documents should only be created when a subject becomes substantial enough to require its own independent system.

The goal is a powerful structure, not a large number of files.

---

# Final Standard

The SAB’A website must never feel like:

- A generic Shopify store
- A catalogue
- A collection of disconnected pages
- A technology showcase
- A discount platform
- A conventional luxury template

It must feel like:

**A digital house.**

A place the visitor enters.

A place that reveals itself gradually.

A place that creates curiosity.

A place that communicates heritage through a contemporary lens.

A place where products are experienced rather than merely displayed.

A place where purchasing feels like a natural continuation of the relationship.

And a place that remains present after the purchase.
