# Website Brand Guidelines

## Purpose

The SAB’A website must express the existing SAB’A identity within a digital environment.

This document does not create a separate digital identity.

It defines how the established SAB’A brand language is translated into:

- Interface
- Typography
- Colour
- Imagery
- Layout
- Spacing
- Motion
- Components
- Interaction
- Responsive experiences

The objective is to ensure that the website feels unmistakably SAB’A while remaining contemporary, refined, functional, and technologically appropriate.

The governing principle is:

**The website does not create a new SAB’A identity. It translates the existing SAB’A identity into a digital environment.**

---

# Brand Expression in Digital Space

The website must communicate the same core character established across the SAB’A Codex:

- Heritage
- Authenticity
- Refinement
- Restraint
- Emotional depth
- Contemporary luxury
- Permanence
- Confidence

The digital environment should feel like a natural extension of the house.

It must never feel as though the website belongs to a different brand simply because the medium is digital.

---

# Digital Luxury

SAB’A expresses luxury through control rather than excess.

Digital luxury is created through:

- Precise typography
- Intentional spacing
- Strong hierarchy
- High-quality imagery
- Refined interaction
- Controlled motion
- Consistent details
- Visual silence
- Performance
- Restraint

Luxury must not depend on:

- Excessive animation
- Decorative effects
- Unnecessary gradients
- Visual clutter
- Excessive interface elements
- Artificial complexity
- Technology for its own sake

The interface should feel considered rather than decorated.

---

# Visual Hierarchy

Every page must establish a clear visual hierarchy.

The visitor should immediately understand:

1. Where they are
2. What they are looking at
3. What matters most
4. What can be explored
5. What action is available

Hierarchy should be achieved through:

- Scale
- Position
- Typography
- Space
- Contrast
- Imagery
- Motion where appropriate

Hierarchy must guide attention without demanding it.

---

# Typography

Typography is one of the primary carriers of SAB’A's digital character.

The established SAB’A typography system remains the source of truth.

The website must preserve the approved:

- Typeface selection
- Font hierarchy
- Weights
- Character
- Proportions
- Language treatment

Digital implementation may adapt sizes and spacing for screen environments, but it must not introduce a competing typographic personality.

### Typography Principles

Typography should feel:

- Refined
- Calm
- Legible
- Confident
- Spacious
- Intentional

Headlines should create presence without shouting.

Body copy should remain highly readable.

Interface typography should be quiet, precise, and functional.

Decorative typography should be used sparingly.

---

# Colour

The approved SAB’A colour system remains the foundation for the website.

Digital applications must translate the existing palette into:

- Backgrounds
- Text
- Borders
- Buttons
- States
- Overlays
- Navigation
- Product presentation
- Supporting interface elements

Colour should establish atmosphere and hierarchy rather than simply fill space.

### Colour Principles

- Preserve the established brand palette.
- Maintain sufficient contrast for readability and accessibility.
- Use colour with restraint.
- Avoid introducing unnecessary colours.
- Do not use gradients merely to create a sense of luxury.
- Allow neutral and negative space to remain part of the visual language.

Colour should support the experience without becoming the experience.

---

# Layout

The website layout should reflect the architectural principles established in:

**1_Website Architecture.md**

The layout should communicate:

- Order
- Proportion
- Depth
- Rhythm
- Space
- Progression

Sections should feel deliberately composed rather than assembled from independent blocks.

The grid should provide structure without becoming visually rigid.

Layout decisions should always consider:

- Content hierarchy
- Visual balance
- Product importance
- Reading rhythm
- Interaction
- Responsive behaviour

---

# Space and Silence

Space is an active component of the SAB’A digital identity.

Generous spacing should be used to:

- Establish hierarchy
- Create calm
- Separate ideas
- Give products room to breathe
- Increase perceived quality
- Control the pace of discovery

Empty space should not automatically be treated as unused space.

In the SAB’A experience:

**Silence is part of the design.**

The interface should not attempt to fill every available area.

---

# Imagery

Imagery must communicate the same level of refinement as the rest of the brand.

Images should feel:

- Intentional
- Atmospheric
- Tactile
- Cinematic where appropriate
- Authentic
- Controlled
- High quality

Product photography must clearly communicate the product while preserving its emotional and material character.

Brand imagery may create atmosphere, narrative, heritage, or emotional context.

### Imagery Principles

Avoid:

- Generic stock imagery
- Visually inconsistent photography
- Excessive filters
- Artificial luxury clichés
- Over-stylised compositions that distract from the subject

Imagery should support the world of SAB’A rather than compete with it.

---

# Cinematic Content

Video and cinematic sequences may be used as major elements of the digital experience.

Their purpose is to:

- Establish atmosphere
- Create emotional depth
- Reveal the brand world
- Introduce products
- Control pacing
- Create memorable moments

Cinematic content must remain intentional.

It should never exist simply because the technology allows video.

Performance, loading, accessibility, and user control must remain part of the decision.

---

# Motion

Motion is part of the SAB’A digital language, but it must remain restrained.

The preferred approach is:

**Purposeful Motion + Luxury Minimalism**

Motion may be used to:

- Reveal information
- Establish continuity
- Guide attention
- Communicate hierarchy
- Transition between spaces
- Add tactility
- Reinforce the feeling of progression

Motion should feel:

- Slow when appropriate
- Controlled
- Smooth
- Quiet
- Predictable
- Intentional

Avoid:

- Excessive animations
- Constant movement
- Distracting parallax
- Unnecessary transitions
- Motion that delays essential interaction

Potential technologies such as Lottie may be used where they genuinely improve the experience, but technology must remain subordinate to the brand.

---

# Interface Components

Every interface component must belong to the SAB’A visual system.

This includes:

- Buttons
- Links
- Forms
- Inputs
- Cards
- Filters
- Selectors
- Search
- Navigation
- Modals
- Notifications
- Product controls
- Cart elements
- Checkout elements

Components should share a consistent:

- Shape language
- Typography
- Spacing
- Motion
- Interaction behaviour
- Visual hierarchy

No component should feel like it was imported from an unrelated template.

---

# Buttons and Calls to Action

Calls to action should be clear without becoming aggressive.

The website should encourage action through confidence and clarity rather than pressure.

Buttons should:

- Have clear labels
- Maintain consistent hierarchy
- Provide appropriate feedback
- Remain visually refined
- Preserve adequate touch targets
- Avoid unnecessary decorative treatment

Primary actions should be visually distinguishable from secondary actions.

Commercial urgency should not dominate the brand experience.

---

# Navigation

Navigation must be visually quiet but functionally clear.

It should feel like part of the architecture rather than an interface layer placed on top of it.

Navigation must maintain:

- Consistency
- Orientation
- Accessibility
- Simplicity
- Hierarchy
- Ease of use

Detailed navigation rules are defined in:

**6_Navigation.md**

---

# Product Presentation

Products must receive the same level of attention as the brand environment around them.

Product presentation should communicate:

- Identity
- Materiality
- Scale
- Character
- Function
- Story
- Value

The interface should avoid reducing products to:

**Image + Name + Price + Buy Button**

Where appropriate, product presentation should allow the visitor to move from:

**Observation → Understanding → Appreciation → Desire → Purchase**

Detailed product-page architecture is defined in:

**5_Product Pages.md**

---

# Interaction Language

Interaction should feel deliberate and tactile.

Every interaction must provide appropriate feedback without becoming theatrical.

Examples include:

- Hover states
- Focus states
- Press states
- Scroll behaviour
- Image transitions
- Product selection
- Cart interactions
- Loading states
- Form validation

The interface should communicate clearly what has happened and what will happen next.

No interaction should leave the visitor uncertain about the state of the system.

---

# Digital Heritage

SAB’A's heritage must remain present without becoming a visual costume.

The website should express heritage through:

- Structure
- Proportion
- Storytelling
- Materials
- Language
- Rhythm
- Spatial progression
- Meaning

Heritage should not depend on repeatedly using:

- Historical motifs
- Decorative patterns
- Literal architectural illustrations
- Excessive traditional ornamentation

The goal is not to make the website look ancient.

The goal is to make it feel **rooted**.

---

# Consistency Across the Website

The SAB’A experience must remain coherent across:

- Homepage
- Collections
- Product pages
- Brand pages
- Content
- Search
- Cart
- Checkout
- Account
- Mobile
- Transactional states
- Post-purchase experiences

A visitor should be able to move between these environments without feeling that the brand changes personality.

---

# Responsive Brand Expression

The SAB’A identity must remain intact across:

- Desktop
- Tablet
- Mobile

Responsive adaptation should not simply reduce desktop elements.

Layouts, typography, imagery, motion, navigation, and interaction must be deliberately adapted to the characteristics of each device.

The smallest screen must still feel like SAB’A.

Detailed mobile requirements are defined in:

**7_Mobile Experience.md**

---

# Accessibility and Inclusion

Luxury does not excuse poor usability.

The website must remain accessible and usable for as many visitors as reasonably possible.

This includes appropriate consideration for:

- Colour contrast
- Typography
- Keyboard navigation
- Focus states
- Touch targets
- Motion sensitivity
- Alternative text
- Semantic structure
- Screen readers
- Clear interaction feedback

Accessibility should be integrated into the system rather than added as a final layer.

---

# Performance as Brand Expression

Performance is part of the luxury experience.

A visually beautiful website that feels slow, unstable, or frustrating does not represent SAB’A at the required standard.

The website should prioritise:

- Fast loading
- Optimised imagery
- Efficient video delivery
- Controlled animation
- Responsive interaction
- Technical stability

The visitor should feel that the experience is effortless.

Performance should remain invisible when it is working correctly.

---

# Consistency Over Time

The website should evolve as SAB’A evolves.

New content, products, features, technologies, and experiences may be introduced.

However, evolution must not create visual fragmentation.

Every new digital element must be evaluated against the existing SAB’A system.

The question is not:

**"Can we add this?"**

The question is:

**"Does this belong?"**

---

# Digital Brand Standard

Before any digital element is approved, it should satisfy the following principles:

- Is it recognisably SAB’A?
- Does it serve a genuine purpose?
- Does it improve the customer experience?
- Does it preserve luxury through restraint?
- Does it respect the existing brand identity?
- Does it work across relevant devices?
- Does it maintain clarity and accessibility?
- Does it remain appropriate as SAB’A evolves?

If an element does not add meaningful value, it should be reconsidered.

---

# Core Standard

The SAB’A website should never look expensive merely because it contains expensive-looking elements.

It should feel luxurious because every decision appears intentional.

The quality must be visible in:

- The typography
- The space
- The imagery
- The interaction
- The movement
- The hierarchy
- The performance
- The consistency

Nothing should feel accidental.

Nothing should feel borrowed from a generic template.

Nothing should exist merely for decoration.

---

# Core Statement

The SAB’A website does not create a new identity.

It translates the identity of the house into a digital environment.

It expresses heritage without imitation.

It expresses luxury without excess.

It uses technology without becoming technological.

It creates emotion without sacrificing clarity.

It evolves without losing recognition.

Every digital detail should contribute to one unmistakable experience:

**SAB’A.**
