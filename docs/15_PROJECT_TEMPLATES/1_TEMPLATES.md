# TEMPLATES

## Purpose

TEMPLATES defines the standard structures used for recurring SAB’A documentation.

Its purpose is to maintain consistency, clarity, and efficiency across the SAB’A Codex.

## Template Principles

Templates should:

- Follow approved Codex standards
- Maintain consistent structure and formatting
- Be clear and practical
- Avoid unnecessary complexity
- Be adapted only when the document requires it

## Standard Document Structure

A standard Codex document should generally include:

- Title
- Purpose
- Relevant sections
- Core Principle
- Credential block

The structure may vary when the subject requires a different format.

## Credential Block

Every completed Codex document should end with:

**SAB’A Codex**  
**Document:** [Exact Filename]  
**Version:** 1.0  
**Status:** Approved  
**Owner:** SAB’A  
**Last Updated:** [Current Date]

The filename must match the actual document name.

## Formatting

Codex documents should:

- Use Markdown
- Use clear headings
- Use concise sections
- Use consistent terminology
- Avoid unnecessary repetition
- Remain readable and easy to maintain

## Template Control

Approved templates should remain consistent across the Codex.

Changes should only be made when they improve clarity, accuracy, or suitability for the intended document.

## Core Principle

> SAB’A templates should create consistency and efficiency while preserving the purpose and clarity of every individual document.
